# OpenKJ 3.1.0 Windows

The MSI installs OpenKJ on Windows x64. For portable use, extract the entire ZIP
and run `openkj.exe` with the bundled DLLs and plugins in place. Both packages
include Qt, GStreamer, FFmpeg and SoundTouch. Windows may prompt because the
packages are unsigned.

OpenKJ 3.1.0 adds paused singers, optional Karaoke and Break Music audio
normalization, and a queue summary on the Rotation Display. It also fixes
opening karaoke ZIP files with Unicode paths on Windows.

Back up your settings and song library before upgrading. See the
[full OpenKJ 3.1.0 changelog](https://github.com/EquinoxEarth/OpenKJ/releases/tag/v3.1.0).
